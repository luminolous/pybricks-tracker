What changed

  • Revision 3 restores items revision 2 dropped or never had: battery gauge, run state, Connect/Disconnect, loop dt red above 2×, motor direction dropdowns, exact-entry tuning fields, overlay with run metrics, replay mode with a timeline.
  • One flat surface split by hairlines instead of floating rounded cards. No glow, no gradients.
  • Plots moved into tabs, which frees room for tuning and events.
  • Instrument details from the robot's own world: a heading tape above the map, centimetre rulers on its edges, protocol event codes in the event list.
  • Actions are a plain list with keyboard shortcuts. Run is the only filled button.
  • One type family: IBM Plex Sans for labels, IBM Plex Mono for every number.
